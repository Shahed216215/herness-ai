- Manual copy, TXT/CSV/JSON/HTML import, public search evidence import, source URL attribution, duplicate content-hash detection, keyword retrieval, record view/update/trash/restore, and retrieval history are wired to Neon-backed APIs.
- CSV/JSON/HTML import extraction is bounded and tested. Credential patterns are redacted; restricted client/financial record markers and private-key/JWT material fail closed.
- Retrieved source text is treated as untrusted evidence, not instructions. Search audit events record metadata only, not the query text or imported post payload.
- Daily Knowledge generation is authenticated, authority-gated, project-scoped, private-only, idempotent, and returns a manual-review draft. It does not publish to Facebook.
- The UI exposes project creation/activation, daily draft generation, source research/import, search, view, update, trash, restore, and history. Controls call real APIs.
