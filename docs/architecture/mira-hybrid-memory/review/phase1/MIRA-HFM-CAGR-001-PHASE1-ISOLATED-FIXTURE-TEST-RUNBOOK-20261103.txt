1. PURPOSE

This runbook executes only source-reviewed, fixture-oriented Memory/Knowledge/Governance tests. It does not run npm test, install packages, fetch remote content, invoke a live model, contact Google Drive, contact Facebook, start the autonomous worker, or run destructive production workflows.

The execution uses the known Termux checkout path. It first checks for a clean working tree and the expected origin, then performs one explicit git fetch for this feature branch and a fast-forward-only update. It never resets, force-checks out, or overwrites local work. After syncing, the six fixture tests run with all relevant storage overrides redirected to a fresh temporary root. The GitHub fetch is the only network step; no provider, Drive, Facebook, or search API is called, and no package is installed.

4. SINGLE OFFLINE COMMAND

Run once from the local Termux checkout. It performs one visible GitHub fetch to synchronize the feature branch, then runs the six selected Node tests offline. It refuses to proceed if the working tree is dirty, origin is wrong, fast-forward is impossible, source code changed after the reviewed baseline, or Node is unavailable. It never uses git reset or force checkout. It redirects known persistence overrides to a fresh temporary directory, unsets provider credentials, prints concise per-test status, and deletes the temporary fixture directory.

```bash
cd "/root/mira-github-upload-staging/herness-ai" 2>/dev/null || { echo "INCONCLUSIVE: repository checkout not found"; exit 2; }
EXPECTED_BRANCH="work/mira-hfm-v025-six-documents"
EXPECTED_ORIGIN="https://github.com/Shahed216215/herness-ai.git"
BASELINE_HEAD="90b48f2816e28686cd499650ff6a5fc6217f0e8a"
[ -z "$(git status --porcelain 2>/dev/null)" ] || { echo "INCONCLUSIVE: working tree is not clean; no changes made"; exit 2; }
ORIGIN_URL="$(git remote get-url origin 2>/dev/null)"
case "$ORIGIN_URL" in *Shahed216215/herness-ai*) ;; *) echo "INCONCLUSIVE: origin does not match expected repository"; exit 2 ;; esac
git fetch origin "$EXPECTED_BRANCH" || { echo "INCONCLUSIVE: GitHub fetch failed; no tests run"; exit 2; }
if git show-ref --verify --quiet "refs/heads/$EXPECTED_BRANCH"; then
  git checkout "$EXPECTED_BRANCH" || { echo "INCONCLUSIVE: could not safely switch to feature branch"; exit 2; }
else
  git checkout -b "$EXPECTED_BRANCH" FETCH_HEAD || { echo "INCONCLUSIVE: could not create local feature branch"; exit 2; }
fi
git merge --ff-only FETCH_HEAD >/dev/null 2>&1 || { echo "INCONCLUSIVE: branch is not fast-forwardable; no reset performed"; exit 2; }
[ "$(git rev-parse HEAD)" = "$(git rev-parse FETCH_HEAD)" ] || { echo "INCONCLUSIVE: local HEAD does not match fetched branch"; exit 2; }
git merge-base --is-ancestor "$BASELINE_HEAD" HEAD || { echo "INCONCLUSIVE: reviewed source baseline is not an ancestor"; exit 2; }
git diff --quiet "$BASELINE_HEAD" HEAD -- "*.js" "*.cjs" "*.mjs" "*.ts" || { echo "INCONCLUSIVE: source/test code changed since reviewed baseline"; exit 2; }
ACTUAL_BRANCH="$(git branch --show-current)"
ACTUAL_HEAD="$(git rev-parse HEAD)"
command -v node >/dev/null 2>&1 || { echo "INCONCLUSIVE: Node.js unavailable"; exit 2; }

TMP_ROOT="$(mktemp -d 2>/dev/null)" || { echo "INCONCLUSIVE: temp directory unavailable"; exit 2; }

export MIRA_STORAGE_DIR="$TMP_ROOT/storage"

FAILED=0
run_test() {
  TEST_PATH="$1"
  TEST_LOG="$TMP_ROOT/$(basename "$TEST_PATH").log"
  if [ ! -f "$TEST_PATH" ]; then
    printf 'INCONCLUSIVE  %s  (file missing)\n' "$TEST_PATH"
    FAILED=1
    return
  fi
  if node "$TEST_PATH" >"$TEST_LOG" 2>&1; then
    printf 'PASS          %s\n' "$TEST_PATH"
  else
    CODE=$?
    printf 'FAIL          %s  (exit=%s)\n' "$TEST_PATH" "$CODE"
    tail -n 12 "$TEST_LOG"
    FAILED=1
  fi
}

echo "=== MIRA HFM ISOLATED FIXTURE TESTS ==="
echo "BRANCH=$ACTUAL_BRANCH"
echo "HEAD=$ACTUAL_HEAD"

  echo "FIXTURE_TEST_RESULT=PASS"
else
  echo "FIXTURE_TEST_RESULT=FAIL_OR_INCONCLUSIVE"
  exit 1
fi
```

5. INTERPRETATION

- A PASS means only that the selected test process exited 0 under the fixture environment; it does not certify production data, provider accounts, Facebook/Drive connectors, or deployment readiness.
- Any missing file, wrong branch/HEAD, missing Node runtime, or test not run is INCONCLUSIVE, never PASS.
- Logs are stored only under TMP_ROOT and deleted by the trap.
- No test modifies the Git working tree by design; if any selected test unexpectedly creates a repository-root data file, stop and report the path rather than cleaning it automatically.
