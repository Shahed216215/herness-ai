5. DATA FLOW / FAILURE SEMANTICS

- Knowledge CRUD writes Local first, then attempts Drive sync. A Drive failure may leave Local updated and Drive stale.
- Controlled apply and Evolution perform more extensive preflight, snapshot, verify, and rollback operations, so they have stronger dependencies than ordinary CRUD.
- Knowledge search allows Drive [] to replace Local source; empty-remote semantics are undefined.
- Backup and restore tools use independent OAuth code and project-root paths, not a common provider-neutral adapter.
- Google Drive JSON payloads are not shown to be encrypted by google-drive.js. No encryption layer was established in the reviewed path.
- OAuth effective scopes and provider retention terms remain unknown.
- No Facebook Page/Group connector path exists in the current branch tree; this is path-level evidence, not proof about manual external operations.
