5. IMPORTANT DATA-FLOW CORRECTIONS

- Knowledge and Learning catalog entries share knowledge.json. Work Learning records in data/work-learning-records.json are a separate record domain. Do not conflate them.
- Experience Memory, Experience Retrieval, Future Strategy, Cross-Task Learning and Learning History are derived/read-oriented layers over Work Learning records; they are not five additional persistent stores.
- Work Knowledge Consolidation is a separate persistent derived-knowledge store.
- Conversation Memory Engine persists through Conversation Store, not the general memory.json Local Store.
- Stage 13 Learning Governance is an additional persistent learning/governance record store.
- Knowledge improvement proposals and autonomous learning proposals are persistent governance stores, not approved Memory records.
- knowledge-search may use Drive state in preference to local state when Drive returns an array. This is a material source-of-truth issue that needs explicit design resolution.
- knowledge-backup and knowledge-restore are active Drive workflows not represented in the previous four-workflow matrix.
- Legacy tool path handling differs: some tools use project-root paths directly while main Knowledge uses mira-storage. Verify whether these paths resolve to the same physical files under non-default storage configuration before migration.
