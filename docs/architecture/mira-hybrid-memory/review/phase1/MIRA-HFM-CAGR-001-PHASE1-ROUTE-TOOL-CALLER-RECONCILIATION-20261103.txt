4. NEW CALLER-LEVEL FINDINGS

T01 — LEARNING TOOL BYPASSES PROPOSAL-ONLY PATH: CONFIRMED.
tools/learning-save.js calls learnFromContent. services/learning.js has instructions stating the Learning Engine must not directly save and should produce data only, but the actual learnFromContent implementation calls addLearning after extraction and duplicate detection. This means the source behavior can persist Learning/Knowledge and trigger Drive sync directly. This is a code/documentation contract mismatch and an important upstream caller/consent boundary to resolve.

T02 — KNOWLEDGE BACKUP SIDE EFFECT: CONFIRMED.
tools/knowledge-backup.js writes the local primary knowledge.json as well as the backup file before its direct Drive upload/update. The operation is not read-only and can rewrite the current Knowledge file even though its tool description describes backup/synchronization.

T03 — KNOWLEDGE CLEANUP ROOT BYPASS: CONFIRMED.
tools/knowledge-cleanup.js writes to a project-root knowledge.json path rather than consistently using the shared mira-storage resolver, then syncs Drive. This can diverge from knowledge.js when MIRA_STORAGE_DIR is configured.

T04 — KNOWLEDGE RESTORE DESTRUCTIVE DUAL-WRITE: CONFIRMED.
tools/knowledge-restore.js may load a Drive backup, create a local safety backup, overwrite project-root knowledge.json, and update Drive knowledge.json. It uses backupVersion=1 and entries-array validation in the reviewed implementation. It was not invoked.

T05 — SEARCH AUTHORITY AMBIGUITY: CONFIRMED.
tools/knowledge-search.js replaces its local search source with any array returned by Drive, including an empty array. The authoritative-source and empty-remote semantics remain undecided.

T06 — PROVIDER EGRESS VIA LEARNING: CONFIRMED.
services/learning.js sends source content in the prompt passed to generate. Provider selection, endpoint, retention, and data handling depend on the configured provider. No request was made.

T07 — AUDIT FAILURE SEMANTICS: INCONSISTENT.
Knowledge Improvement's local writeAudit helper catches/swallow errors and returns a status that some callers ignore. Autonomous Learning's helper propagates recordAudit errors. Knowledge Improvement apply also has handled early-return branches without route-level audit events. Lower-level coverage is not exhaustively proven.

T08 — DISTINCT MEMORY DOMAINS: CONFIRMED.
General Memory, Conversation Store, Work Learning Records, Work Knowledge Consolidation, Stage13 Learning Governance, proposals, and Audit Log are distinct persistence domains. They must not be collapsed into a single file merely because they contain memory/learning-like records.
