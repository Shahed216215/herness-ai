6. KNOWN LIMITATIONS
- Trusted host authentication/authorization implementation is not present; callbacks are injected dependencies and must be bound to the real authenticated host before runtime use.
- Project mapping validator does not create, approve, persist, revoke or authenticate mappings; it validates supplied mapping evidence only.
- Unified facade is in-memory and synthetic. It does not connect to Memory, Knowledge, CRM, Drive, Facebook, caches, embeddings, routes, tools, Evolution, backup or restore.
- Write facade only prepares a candidate; it does not commit, provide provider CAS, persist idempotency keys or write audit records.
- Provider-enforced CAS/distributed arbitration, immutable production mapping registry, full caller coverage, remote trust anchor, encryption and backup remain open.
- Work Learning, Work Knowledge and Experience Memory authoritative project relations are not established.
- General Memory historical immutable identity remains unavailable; no backfill is authorized.
- Phase 2 recovery limitations and PR #4 review state remain dependencies.
